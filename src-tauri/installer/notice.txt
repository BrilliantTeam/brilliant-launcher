Brilliant Launcher｜輝煌啟動器 隱私權說明

完整條款：https://www.brilliantw.net/%E9%9A%B1%E7%A7%81%E6%94%BF%E7%AD%96/ （第七節「輝煌啟動器」）

【存放在你電腦上的資料】
帳號資訊（遊戲名稱、UUID、Microsoft／Minecraft 登入憑證）、設定、遊戲實例、存檔備份與皮膚衣櫃，都存放在 %APPDATA%\BrilliantLauncher（Linux 為 ~/.local/share/BrilliantLauncher）。
登入憑證只用來向 Microsoft／Mojang 驗證身分，不會傳送給輝煌。
啟動器不含廣告或第三方分析程式，不會回傳硬體資訊、遊戲日誌或當機報告。
匿名使用統計：檢查更新時會附上隨機產生的安裝識別碼、啟動器版本與作業系統類型，用來統計使用人數；與帳號、遊戲名稱無關，官網只保存雜湊值、保留 90 天，可在設定中關閉。
錯誤回報：遊戲崩潰或啟動失敗時，只有你按下「回報給管理員」才會送出錯誤摘要與最後一段日誌（已遮蔽帳號名稱、UUID 與電腦使用者名稱），保留 30 天。

【會連線的服務】
・Microsoft、Xbox Live、Mojang：正版登入、自動續期、皮膚／披風／名稱變更；截圖投稿時向 Mojang 證明帳號身分
・Minecraft 官方下載：遊戲本體、函式庫、資源檔與 Java
・BMCLAPI 鏡像（bmclapi2.bangbang93.com）：加速下載，可在設定中關閉
・Fabric：模組載入器
・Eclipse Adoptium：Mojang 的 Java 下載失敗時的備用來源
・Modrinth：搜尋與下載模組、資源包、光影；檢查更新時會送出已安裝檔案的 SHA-1 雜湊值
・輝煌官網 www.brilliantw.net：公告、分流人數、更新、伺服器資源包；開啟「我的輝煌」時以 UUID 查詢公開的遊戲統計；主動投稿截圖時上傳截圖、說明，並記錄遊戲名稱、UUID 與已綁定的 Discord 帳號以供審核
・輝煌伺服器分流：查詢線上人數與延遲
・api.mineatar.io、mc-heads.net、textures.minecraft.net：頭像與皮膚圖片

上述第三方服務會依各自的隱私政策處理你的連線資訊（例如 IP 位址）。

【你可以控制的項目】
・在「設定」中關閉 BMCLAPI 鏡像、系統通知、開機自動啟動與匿名使用統計
・不按「投稿」就不會上傳任何截圖
・不開啟「我的輝煌」就不會查詢遊戲統計
・解除安裝後刪除 %APPDATA%\BrilliantLauncher 即可移除所有本機資料（包含存檔，請先自行備份）
