    遊戲

    MB，0 為不設定
    設定後遊戲一開始就向系統要這麼多記憶體，減少執行中擴充記憶體造成的卡頓；超過上限時會自動以上限為準。
    遊戲視窗設定目前只支援 Windows。「無邊框全螢幕」會在遊戲視窗出現後自動套用，不要同時勾選上方的「全螢幕啟動」。
    開啟後，每次遊戲結束會記下勾選的選項，下次開任何實例時自動套用，不用每個實例重設。語言、資源包等其他選項不受影響。
    選「自動」時，啟動器會依版本需求下載 Mojang 官方 JRE，或沿用系統上版本相符的 Java。
    Mojang 內建的 Java 很少更新，可能缺少安全修補。開啟後，Java 選「自動」的實例每次開始遊戲前會檢查 Adoptium（Eclipse Temurin）有沒有新版，有的話自動下載並校驗後換上；檢查失敗或離線時沿用現有的 Java。
    留空會套用 Mojang 官方啟動器的 G1 GC 預設值。每個實例也可以在「實例 → 設定 → 進階」個別覆寫。
    只套用在輝煌實例；一般實例一律進主畫面。
    僅對 Fabric 實例生效。每次啟動時從官網下載最新版本與對應的 Fabric API，並清掉舊版的 jar。

    啟動流程

    份自動備份
    備份存在實例資料夾的 backups，可在「實例 → 更多 → 存檔備份」還原。
    可使用環境變數 %INST_NAME%、%INST_DIR%、%INST_MC_VER%；結束指令另有 %EXIT_CODE%。啟動前指令失敗時會取消啟動。

    外觀

    切換後介面會重新載入。實例名稱、遊戲日誌與官網公告維持原文。
    一鍵套用整組外觀，套用後仍可以在下面逐項微調。
    匯出或匯入的外觀會存在這裡，點一下就能切換；也可以把 .brlook 外觀檔拖到這裡匯入。
    載入中⋯
    輝煌玩家分享的風格組合。把你匯出的 .brlook 外觀檔分享到輝煌 Discord，精選作品會上架到這裡。

    顏色與主題

    開啟後，主題色、輔助色與進階配色會鎖住，全部改用從背景自動產生的顏色；你手動設定的值會保留，關掉就恢復。主題選「跟著背景亮度」時，背景偏亮用亮色、偏暗用深色。
    留空使用預設顏色。

    字體

    支援 TTF、OTF、WOFF、WOFF2，可以一次選多個，也可以直接把字型檔拖進來。點「使用」切換；右上角的字型按鈕也會輪流切換到這些字型。字型缺少的字（例如中文）會用黑體補上。
    只放大文字，版面不變；想整個介面一起放大請用下面的「介面縮放」。

    按鈕與版面

    調低後會透出主頁背景，面板加上霧化效果，文字仍保持清楚。

    主頁背景

    支援 PNG、JPG、WebP、GIF 圖片與 MP4、WebM 影片（影片會靜音循環播放）。
    點一張固定使用它；選「隨機輪播」恢復輪流顯示。使用自訂檔案時這裡不會生效。
    背景圖片太亮、看不清公告或分流資訊時調高。

    主頁

    只留下自己常去的分流；隱藏的分流仍可以用遊戲內的指令前往。
    可以拖曳每個主頁元件、調整大小，並開關「遊玩統計」「便條」「活動倒數」等小工具；主頁右側的筆形按鈕也能進入編輯。
    「活動倒數」小工具預設顯示輝煌的下一個官方活動；填了自訂倒數且時間還沒到時，改為顯示自訂的倒數。
    支援 MP3、OGG、WAV、M4A、FLAC、Opus，可以一次加入多首。遊戲執行中或啟動器縮到背景時會自動暫停。

    實例

    每個實例也可以在「實例設定」裡指定自己的主題色，進入該實例時整頁會換成那個顏色。

    側欄與導航

    用箭頭調整順序，取消勾選可以隱藏不常用的分頁；首頁、實例、設定與關於不能隱藏。
    最多 8 個，會顯示在側欄下方；側欄只顯示名稱的前 4 個字。

    動畫與回饋

    進階

    把遊戲交給這個指令來啟動，例如 Linux 的 gamemoderun、mangohud、prime-run。包含空格的路徑請用雙引號包起來。每個實例也可以個別覆寫。
    套用在所有實例；實例裡設定的同名變數會覆蓋這裡的值。
    筆電同時有內建與獨立顯示卡時建議開啟。Windows 會在系統的「圖形設定」把遊戲用的 Java 設為高效能；Linux 會加上 PRIME offload 的環境變數。
    讓多個實例共用存檔、資源包、光影或截圖，不用每個實例各放一份。
    已鎖定版本的模組與「凍結模組」的實例會跳過。
    每個實例保留最近 5 份；模組壞掉時到實例頁的「模組快照」一鍵還原。10 分鐘內連續安裝只會存一份。
    學校或公司網路需要代理才能下載時使用，啟動器與遊戲內的連線都會走這個代理。目前支援 HTTP／HTTPS 代理；格式正確後才會自動儲存。
    回報模組衝突或當機時很有用；平常建議關閉。實例的「更多 → 匯出診斷包」可以把日誌、當機報告與模組清單打包成一個檔案（會自動隱藏登入憑證）。

    更新與安全

    只影響輝煌啟動器本身，輝煌模組不分通道、一律使用最新版。正式版的每個版本都先經過 Beta 測試；從 Beta 換回正式版時，會在下一個正式版推出時自動換回，不會降級。還沒有正式版或 Beta 時，會先拿到最新的 Alpha。
    啟動器與輝煌模組的每個更新檔都附有輝煌官方的數位簽章。下載後會先用啟動器內建的公鑰驗證，內容被竄改或不是官方發布的檔案一律拒絕安裝，就算官網或下載途中出問題也一樣。選擇「保持目前已安裝的版本」時，伺服器升版後可能要手動改回自動更新才能連線。

    系統與下載

    網路不穩或下載常失敗時調低；頻寬充足時調高可加快首次安裝。

    資料

    方案會記住記憶體、JVM 參數、啟動流程與所有外觀設定，一鍵切換；帳號、實例、分組與下載的檔案不受影響。也可以在指令面板搜尋「方案」快速套用。
    隱藏畫面上的帳號名稱、信箱、伺服器 IP、電腦路徑與截圖座標；上傳日誌、匯出診斷包時也會一併遮蔽 IP、信箱與玩家名稱。
    清理快取會刪除可自動重建的 natives、7 天前的日誌，以及回收資料夾裡超過 30 天的項目，不會動到存檔、模組與設定。
    匯出設定會把啟動器設定與所有實例的設定打包到「下載」資料夾（不含帳號登入資料與遊戲檔案），換電腦時匯入就能還原，遊戲檔案會在第一次開始遊戲時自動下載。

    快捷鍵

    按 Ctrl + K（可在下方修改）打開，輸入文字就能啟動實例、跳到任何設定、開資料夾、切換帳號或套用設定方案。
    啟動器縮到背景或工作列時也有效，按下就直接開始遊戲（目前選擇的實例）。
    點按鈕後按下新的組合鍵；Esc 取消、Backspace 清除。輸入文字時只有含 Ctrl 或 Alt 的快捷鍵會生效。
