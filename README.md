# 輝煌啟動器

[輝煌 Brilliant](https://www.brilliantw.net) 伺服器的 Minecraft 啟動器。

下載：<https://www.brilliantw.net/launcher/>

支援 Windows、macOS、Linux 與 Android。Android 版目前在 Google Play 封閉測試，只開放受邀玩家。

## 功能

- 微軟正版登入（透過瀏覽器，可沿用瀏覽器已登入的微軟帳號與通行金鑰），登入狀態自動續期；電腦版另可使用離線帳號
- 一鍵直連四個分流，即時顯示線上人數、延遲與每日重啟時間
- 首頁公告、伺服器活動提醒，以及「我的輝煌」個人遊戲統計
- 實例管理：原版、Fabric、Forge、NeoForge，記憶體、封面圖、世界管理、存檔備份、效能健檢
- Modrinth 與 CurseForge 模組、資源包、光影商店，含推薦組合、前置檢查、版本切換
- 模組組合切換，可匯出或匯入 `.mrpack` 模組包
- 資源包優先順序調整
- 3D 皮膚預覽、衣櫃、披風與改名
- 相簿與每週回顧，截圖可投稿到官網「玩家足跡」
- 探索合作伺服器與推薦作品
- 從官方啟動器、Prism、MultiMC、CurseForge、Modrinth App、X Minecraft Launcher 匯入
- 伺服器升版時一鍵升級實例、自動安裝 Brilliant-Server-Mod
- 遊戲崩潰或啟動失敗時自動分析原因，可選擇要附上的資料回報給管理員，並在「我的回報」追蹤進度與回覆
- 安裝可能違反輝煌服規的模組時提醒
- 沒有網路時自動切換為離線模式，已下載的實例仍可遊玩
- 電腦版自動更新，分為正式版、Beta 與 Alpha 通道；每個更新檔都經過輝煌的數位簽章驗證才會安裝（Android 版由 Google Play 更新）
- 自訂背景、背景音樂、強調色、介面縮放與快捷鍵，也可以開啟官網的虛擬夥伴

## Android 版

- 為觸控重新設計的介面：首頁只留實例、分流與開始遊戲，對話框改為側邊浮層，可切換左手操作
- 遊戲內觸控按鍵使用圖示，不常用的按鍵收在「快捷動作」選單；按鍵編輯器可自訂位置、大小與圖示
- 輝煌實例預設安裝 Sodium、ImmediatelyFast、FerriteCore、Lithium、Entity Culling 等效能模組
- 實例資料可放在手機內部，或搬到手機儲存空間、SD 卡的 App 專屬資料夾；系統「檔案」App 的側邊選單可直接管理模組、資源包與存檔
- 長按桌面圖示可快速開始遊戲、選擇分流、看公告或管理實例
- 需要 Android 7.0 以上的 64 位元手機，建議 6 GB 以上記憶體；只能使用微軟正版帳號
