# 輝煌啟動器

[輝煌 Brilliant](https://www.brilliantw.net) 伺服器的 Minecraft 啟動器。

下載：<https://www.brilliantw.net/launcher/>

支援 Windows、macOS 與 Linux。

## 功能

- 微軟正版登入（透過瀏覽器，可沿用瀏覽器已登入的微軟帳號與通行金鑰）與離線帳號，登入狀態自動續期
- 一鍵直連四個分流，即時顯示線上人數、延遲與每日重啟時間
- 首頁公告、伺服器活動提醒，以及「我的輝煌」個人遊戲統計
- 實例管理：版本、Fabric、記憶體、封面圖、世界管理、存檔備份、效能健檢
- Modrinth 模組、資源包、光影商店，含推薦組合、前置檢查、版本切換
- 模組組合切換，可匯出或匯入 `.mrpack` 模組包
- 資源包優先順序調整
- 3D 皮膚預覽、衣櫃、披風與改名
- 相簿與每週回顧，截圖可投稿到官網「玩家足跡」
- 探索合作伺服器與推薦作品
- 從官方啟動器、Prism、MultiMC、CurseForge、Modrinth App、X Minecraft Launcher 匯入
- 伺服器升版時一鍵升級實例、自動安裝 Brilliant-Server-Mod
- 遊戲崩潰或啟動失敗時自動分析原因，可選擇要附上的資料回報給管理員，並在「我的回報」追蹤進度與回覆
- 安裝可能違反輝煌服規的模組時提醒
- 沒有網路時自動切換為離線模式，已下載的實例仍可遊玩
- 自動更新，分為正式版、Beta 與 Alpha 通道；每個更新檔都經過輝煌的數位簽章驗證才會安裝
- 自訂背景、背景音樂、強調色、介面縮放與快捷鍵，也可以開啟官網的虛擬夥伴
