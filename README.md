# 輝煌啟動器

[輝煌 Brilliant](https://www.brilliantw.net) 伺服器的 Minecraft 啟動器。

下載：<https://www.brilliantw.net/launcher/>

## 功能

- 微軟正版登入與離線帳號，登入狀態自動續期
- 一鍵直連四個分流，即時顯示線上人數與延遲
- 實例管理：版本、Fabric、記憶體、封面圖、世界管理、存檔備份
- Modrinth 模組、資源包、光影商店，含推薦組合、前置檢查、版本切換
- 模組組合切換，可匯出或匯入 `.mrpack` 模組包
- 資源包優先順序調整
- 3D 皮膚預覽、衣櫃、披風與改名
- 從官方啟動器、Prism、MultiMC、CurseForge、Modrinth App、X Minecraft Launcher 匯入
- 伺服器升版時一鍵升級實例、自動安裝 Brilliant-Server-Mod
